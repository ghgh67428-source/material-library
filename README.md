# material-library

更新：2026-11-27。网站地址：https://ghgh67428-source.github.io/material-library/

- 232 项材质，其中 34 项配有应用实景，覆盖 10 个分类。
- 58 张选用的项目照片保存在 `images/applications/`，主图逐项聚焦材料构件，详情对照材料做法与使用位置。
- 卡片直接标明材料名称、具体部位和完成效果；保留完整原图，取景仅在页面中调整。
- 默认进入应用实景；可切换全部材质、228 项纹理样本。
- 实景详情保留摄影署名、谷德项目来源和材料对应说明；不确定的细分规格标注为同类应用参考。
- 原有 400 条植物数据保留。

从本目录运行 `python -m http.server 8772 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:8772/`。

应用实景使用 WebP 双尺寸：详情图长边最多 1280px，列表图最多 720px。资产清单及校验值见 `data/application-assets.json`。发布通过 Git 增量推送，未改文件不重复上传。
